Formularios de html

Texto

Campo de texto basico: simple placeholder, obligatorio (required), de lectura(readonly) y desabilitado(disabled)





Contacto

Campo especializados para datos de contacto: contraseña, correo electronico, telefono, url, cada uno con su propio teclado y validacion del navegador.





Numericos

Campos para valores numéricos: un número con límites (min/max) y un deslizador (range) para elegir un valor dentro de un rango.



Fecha y hora

Selectores nativos de fecha y hora: fecha, fecha y hora combinadas, hora, semana del año y mes.






Seleccion

Controles de selección: elegir un color, marcar una casilla, elegir una opción de un grupo de radios y subir un archivo.





Listas desplegables (select)

Listas desplegables con el elemento select: una opción simple, una con valor preseleccionado (selected), una agrupada con optgroup, una de selección múltiple (multiple) y una deshabilitada (disabled).
